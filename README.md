**Proposed Feature:**
•	User registration, login and private dataset management
•	CSV and Excel upload, preview, automatic column and data-type detection
•	Automated data-quality analysis and cleaning with preview
•	Exploratory data analysis and interactive dashboards
•	AI assistant for natural-language questions, insights and chart recommendations
•	Basic machine learning: classification, regression, forecasting and clustering, where the dataset is suitable
•	PDF and Excel report export
•	Deployment, testing and documentation
